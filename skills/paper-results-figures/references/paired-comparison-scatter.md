# Paired Comparison Scatter

## Data and inference

Use one row per matched observation, with numeric x and y values for the same metric. The focal model normally goes on y and the comparison model on x. For higher-is-better scores, values above the equality line favor the focal model. Preserve explicit user choices even when the observed ordering differs. Supply an `id` whenever a unique pairing key exists. A missing or duplicate key fails validation.

Inspect the actual input before configuring these fields. A long table with one method/value row per observation can be reshaped by explicit pairing ID and selected x/y methods using [input preparation](data-preparation.md). Keep identifier strings, including leading zeros, and preserve covariates and source values. Unmatched or duplicate pairing keys and differing paired covariates need an established scientific rule; do not average or pair by current row order. Save any necessary transformation and lineage with the external figure.

The one-sided paired t-test uses exactly the plotted finite pairs. `greater` tests mean(y - x) > 0; `less` tests mean(y - x) < 0. Neither the sign of the observed result nor a smaller p-value determines the test direction. All points, including ties and unfavorable pairs, remain present. Fewer than three finite pairs or effectively constant differences produce an error. The selected sampling unit must support independent paired differences; an observation-level t-test does not adjust for clustering.

Establish the metric and observation unit from the current task and data. Do not inherit metric labels or repeated-observation assumptions from a previous example. Inspect identifiers and metadata values rather than trusting column names alone. If the same underlying unit appears in multiple groups, explain the limitation of a pooled row-level test; if identifiers are unique, report that observed structure. Preserve user-supplied metric provenance when the file does not encode it explicitly.

Read the [shared style guide](style-guide.md) for the common numeric, typography, transparency, and legend rules.

## Visual contract

- Square plotting panel with `coord_fixed(ratio = 1)` and identical linear limits, tick locations and labels on both axes. Actual Arial endpoint glyph extents reserve outer canvas margins with 0.35 mm clearance; the fixed requested canvas stays unchanged, and the square panel and internal annotations are measured after this allocation. `axis_canvas_layout` records the resolved margins and glyph measurements. Inspect complete endpoint glyphs in PNG/PDF, including the top Y tick and right X tick, rather than only checking tick presence.
- Dashed y = x diagonal; vertical dotted mean(x) and horizontal dotted mean(y). Optional marginal histogram densities/KDE use the same retained pairs without changing these means or the test.
- White background, dark panel border, no grid. Points retain fixed palette-specific opacity and the paired-only RGB transform. Green-blue-purple uses 0.12 darkening; ordinary rainbow paired scatter uses 0.00. The `rainbow-transparent` marginal layout uses the deeper point profile below. Bar/distribution appearance is unaffected.
- A rectangular 90%-opaque white statistics frame, normally lower right, with exactly two centered lines and no heading: `t-statistics = ...` and `p-value ...`. Values use three decimals; p < 0.05 displays `p-value < 0.05`. Full-precision values and hypothesis remain in statistics JSON.
- Measure actual Arial text on the final square panel. Internal statistics and category/size guide fonts scale by measured panel width / `annotation_reference_mm` (40 mm). Statistics use base `stats_font_size: 2.2`; category/size labels use base 2.0 mm and titles 2.3 mm. Configurations retain these base sizes, with actual scaled sizes recorded separately, preventing repeated scaling on rerender.
- `stats_box`, `legend_box` and `size_legend_box` default to null for measured automatic frames. Statistics reserve 3% horizontal padding on each side of the longest line; category legends reserve 6% on each side of the widest title/key row. If automatic statistics/category widths differ by no more than `guide_width_match_tolerance: 0.08` of the larger width, use the same width when the complete readable frames remain safe and per-side padding stays within `guide_width_match_max_padding_fraction: 0.10`. Explicit normalized boxes are preserved; text must fit rather than silently shrinking. Inspect any reported statistics overlap and refine its placement.
- Category labels are left-aligned in each column while the complete key/text block is centered. Three categories use two entries on the first row and one centered on the second; four to six use two columns. A concurrent size guide or insufficient empty space can require the category legend outside.
- Numeric size has a separate framed guide, preferably above statistics, with a 9 mm minimum height at the reference panel and 0.65 mm inner padding for title, symbols and labels. Count-size labels are integers; measured-size labels have three decimals. Missing color is gray; missing size uses fixed `point_size`, with counts recorded and no change to the paired sample. Stars replace selected marks without changing their inclusion.
- Continuous color uses a framed labeled numeric axis, outside the panel by default (`colorbar_placement: outside`). An explicit `auto` or `inside` request enables safe measured interior placement. It may be horizontal or vertical; automatic orientation checks complete title/tick clearance rather than requiring a vertical gradient. It remains a numeric axis with a gradient, title and ticks; categorical legends are not a substitute. The full guide frame must fit without covering points, labels, statistics or the internal size guide.

## Continuous color axis

Establish whether a numeric column is a measurement or a category code from its meaning, not storage type. Clarify unresolved meaning before plotting. Set `color_type: continuous` for a numeric covariate and state its meaning/units in `color_label`.

Use the palette's continuous stops after the fixed paired transform, with the same opacity as the points. Automatic limits span every finite retained covariate; a constant measurement gets a small visible interval. Explicit limits must contain every finite value. Missing covariates remain gray without changing the test sample.

`colorbar_placement: outside` is the default, with a vertical guide on the right when orientation is automatic. Explicit `colorbar_placement: auto` opts into a readable internal axis when a complete empty rectangle fits; it uses the external guide when no safe inside candidate exists. `colorbar_orientation: auto` evaluates horizontal and vertical candidates; an explicit orientation preserves the requested direction and requires readable fit. It measures the gradient, complete title, short tick marks and tick labels, background and padding against physical point edges, point labels, statistics and any inside size guide; otherwise it restores the native external right-hand axis. `inside` requires a verified safe fit and errors when none exists, so refine `colorbar_box`, dimensions or canvas. `outside` requests the external guide: automatic orientation remains vertical on the right; explicit `horizontal` uses the bottom. Internal `auto` checks both orientations and chooses the smallest safe complete frame. Category `legend_placement` and size-guide placement do not control the continuous axis.

An explicit `colorbar_box` is the normalized rectangle for the **whole internal guide**, including title, ticks and background. Without one, the renderer checks measured candidates in available corners and other empty regions. Internal gradient length starts at `colorbar_inside_height_mm: 12`, scaled by panel width / 40, for either orientation; it can grow to fit complete tick labels. The internal title starts at `colorbar_inside_title_size: 2.0` mm and tick text at `colorbar_text_size: 1.6` mm, with the same proportional scale. Internal wrapping starts at `colorbar_inside_title_width: 24` characters, allowing a title such as “Numeric covariate” to stay on one line when the complete frame fits safely. Explicit title newlines are preserved. `colorbar_padding_mm: 0.6`, `colorbar_title_gap_mm: 0.65` and `colorbar_tick_gap_mm: 0.45` reserve measured inner clearance. Recheck every title, tick and background rather than compressing them into a fixed rectangle. Outside title/ticks remain absolute 1.6 mm (`colorbar_title_size`, `colorbar_text_size`), with compact wrapping at `colorbar_title_width: 14`, independent of category-legend typography. An explicitly supplied legacy `colorbar_title_size` or `colorbar_title_width` also controls the internal title unless the corresponding internal key is supplied. The outside panel gap starts at 0.65 mm; width starts at 1.8 mm. Automatic outside height derives from the canvas, with a 14 mm minimum, and remains adjustable.

Internal numeric guides always have exactly three positions: the lower limit, arithmetic midpoint `(lower + upper) / 2`, and upper limit, at normalized gradient positions 0, 0.5 and 1. `colorbar_breaks` controls exterior ticks only; internal placement uses those three positions even when requested external breaks differ. Keep the gradient clear, with no black separators across it. At each displayed break, draw a short inward tick from the label-side boundary: the right boundary for vertical gradients or the bottom boundary for horizontal gradients. `colorbar_tick_length_mm: 0.6` scales by panel width / 40 inside and remains absolute outside; its length must be less than the gradient thickness. Effective `colorbar_tick_offset_mm` is always 0. The legacy offset key remains accepted for saved-config compatibility, but old nonzero values are recorded and ignored. Tick text retains its measured clearance beyond the gradient boundary. Retain readable labeled ticks and an identifiable covariate title in either mode. Record chosen placement, resolved whole-frame geometry, measured panel size, scale factor, effective font sizes, gradient dimensions, limits/breaks and occupancy checks in statistics. `color_scale.direction`/`placement` and the inside candidate's `component_bounds_mm` retain the orientation and measured title/tick fit. `external_breaks`/`external_labels`, `internal_breaks`/`internal_labels`, `internal_break_rule` and `separator_lines: none` record the configured exterior ticks, computed three-position interior ticks and the set actually used. `tick_marks: short inward`, `tick_boundary`, `tick_length_mm` and `tick_offset_mm: 0` record the inward treatment; `legacy_tick_offset_requested_mm` and `tick_offset_policy` retain the compatibility decision; separate internal/external title text, sizes and wrapping widths retain the title policy. Size-guide records retain actual height, padding and row positions, and `annotation_layout.frame_width_matching` records whether/why automatic category and statistics widths matched. Inspect the actual export at print size; a small gradient that fits while its title or tick text overlaps is not a safe placement.

## Optional marginal histograms and KDE

Set `marginals: true` to add X/reference distributions above and Y/focal distributions on the right. Default false preserves the ordinary paired figure. Use the same finite pairs as the plotted scatter and t-test, including observations with missing visual covariates. Marginals pool each method's scores regardless of color grouping; they do not stratify by the color covariate or change pairing, means, ordering or significance.

Histogram heights use density (count / retained count / bin width), so each histogram has total area one. `marginal_bins: 8` supplies common edges across the shared x/y interval. KDE uses `marginal_bandwidth: nrd0` by default, with a smoothed density curve separate from the histogram. Omit KDE for constant scores or fewer than `marginal_kde_min_n: 5` retained observations, recording the reason; keep the histogram and all finite pairs. KDE is a descriptive display, not a confidence interval or a test.

Each strip starts at `marginal_strip_mm: 6` with `marginal_gap_mm: 0.65`. The complete canvas dimensions include both strips, titles and axis text; the main scatter panel remains square with matching score ticks. Annotation scale is recalculated from that main panel. Increase the canvas if the reduced panel cannot support readable annotations; do not hide pairs to fit.

With `rainbow-transparent` and `marginals: true`, omitted/null `point_alpha` and `point_darken` resolve to 0.90 and 0.20. This fixed layout profile makes the small scatter marks easier to see on white while retaining the palette's base RGB slots and group assignments. Apply it consistently to points, category keys and continuous color guides; marginal method anchors use the same paired transform. Explicit/saved values still take precedence. Other palettes and ordinary scatter retain their palette defaults.

Marginal fills start at `marginal_alpha: 0.35`. Optional `marginal_reference_color`/`marginal_focal_color` override the two method colors; null uses the selected palette's second/third anchors after its paired transform. Keep these method colors distinct from a categorical covariate legend's meanings. The statistics record contains counts, edges, density heights, KDE settings/results or omission reasons, method colors and physical geometry.

See the synthetic [configuration](../examples/paired-comparison-scatter-marginals/prompt.md) and [preview](../examples/paired-comparison-scatter-marginals/preview.png).

## Numeric sizes and selected stars

Use `size` for a numeric covariate with stated meaning and units. Symbol area is affine in the raw covariate; `size_range` specifies exact minimum/maximum physical circle-equivalent diameters in mm, and optional `size_breaks` chooses readable guide values. Set `size_type: count` for actual counts such as sample count or nucleotide count; these values and guide breaks must be nonnegative whole numbers and their labels have no decimal suffix. Measured quantities use `size_type: continuous` and three-decimal labels. Establish this meaning from the scientific brief; integer-valued storage alone does not establish a count. A sparse example with continuous color, an internal count-size guide and two explicitly selected stars is available as [configuration](../examples/paired-comparison-scatter-size-stars/prompt.md) and [preview](../examples/paired-comparison-scatter-size-stars/preview.png). It uses fictional observations only.

The mapping is `u=(value−v_min)/(v_max−v_min)`, `D=sqrt(D_min²+u·(D_max²−D_min²))`, and geometric area `A=πD²/4`. This preserves both diameter endpoints and interpolates **area** linearly in raw value. A positive minimum diameter introduces an area offset: do not describe this as area proportional through zero, or interpret area ratios as raw-value ratios. A constant covariate uses `u=0.5` (the midpoint of the endpoint **areas**) and a single guide value. Finite circles are explicit physical circles without outline strokes. Stars have inner/outer radius ratio 0.45 and are normalized to the same exact area. Size-guide circles are hollow; their stroke is drawn inward so the outer envelope diameter equals the plotted diameter. The nominal outline is 0.145520833 mm; for smaller supplied diameters it is capped at D/3 to preserve a hollow center and the same outer extent. Missing size values retain the legacy fixed-size fallback and have no assigned numerical area. The plotted-data and statistical records retain raw values, mapped diameters/areas, the affine slope/intercept, and guide geometry. Neither size nor shape changes equal per-pair statistical weights.


The size guide defaults to `auto`: prefer its white framed rectangle inside the panel above the statistics box, with hollow circles, integer or measured labels and an increasing-size arrow. Automatic frames reserve `size_legend_min_height_mm: 9` and `size_legend_padding_mm: 0.65` at the reference panel, scaled with the other internal annotations; the tallest title, symbol and label determine any further growth. This leaves visible top/bottom clearance without changing point sizes or data. The automatic starting breaks are three representative values within the observed finite range, rounded only for counts. Candidate checks consider point edges, text width and separation from the statistics frame; inspect the actual export. `size_legend_placement: inside` requires a safe readable interior frame and fails if the candidate would cover data or crowd labels, so revise the box, sizes or canvas rather than silently moving an explicitly requested guide outside. `auto` can use an external guide when no safe candidate fits; `outside` explicitly requests it. Continuous color has its independent measured `colorbar_placement` decision.

Set `star_ids` to raw values of an explicit unique `id` column. Stars are physical five-point polygons rather than font glyphs. For finite size-mapped values their polygon area exactly equals that of a physical circle with the same mapped diameter; they retain each point's color and opacity, and a missing size retains the fixed-size fallback. The stars replace their corresponding circles; they do not duplicate observations or create a separate shape guide. Selection must come from the user's requested IDs or an established scientific rule, not whichever observations make the comparison favorable. Unknown or excluded IDs fail validation.

`point_labels` optionally maps retained IDs to text. Label colors follow point colors. Omitted offsets use deterministic candidate placement measured in actual Arial on the final panel, with 0.35 mm clearance from conservative circle/star envelopes, other labels, equality/mean reference lines and internal annotation frames, and 0.25 mm from panel boundaries. Fixed labels constrain guide placement; automatic labels fit around the final internal frames. Placement decisions and glyph bounds are recorded in `point_label_placement` in the resolved configuration and statistics. Explicit per-ID `point_label_offsets` remain `[dx, dy]` fractions of the shared axis span and are preserved; their recorded collision checks still require inspection. If no safe automatic candidate exists, the renderer requests a larger canvas or an explicit inspected placement. No label is added without an explicit map. All observations still contribute to means and the paired t-test. Adapt the internal size frame, numeric color axis and statistics frame together to keep the panel square and the text readable.

## Files and review

The renderer writes `.pdf`, `.svg`, `.png`, `.statistics.json`, `.config.json`, `.plotted-data.csv`, and `.session.txt` together in the dedicated figure folder next to the normalized output prefix. Keep input configurations, QA, and reproduction files in this same folder as well. Statistics include full-precision numeric values, logarithmic p-value, one-sided confidence limits (strings preserve Infinity), input row counts and exclusion indices, means, mapping, and provenance hashes. The source CSV is never edited. The resolved configuration can reproduce the figure; rerunning the same prefix deliberately replaces that figure's outputs.

Inspect the PNG at normal reading size. Check that all category entries are distinguishable, every tick has a label, the statistic text fits inside the box, and neither annotations nor legends conceal observations. Increase canvas size or adjust the annotation position when needed; do not solve crowding by silently removing data. All formats must use actual Arial. The exporter verifies embedded Arial in PDF and embeds the font in editable SVG; inspect layout after typography changes.

The category guide supports up to six entries without a concurrent size guide, with widths measured from actual Arial labels rather than a character-count limit. Check complete frame occupancy against symbol edges and labels; other or crowded cases use the native framed external guide. Continuous and size guides have their own measured placement checks. Inspect after changes to canvas, fonts or marginals.

All layout settings in the example are initial candidates. For each dataset, inspect the rendered result and adapt the common axes, canvas, legend frame, statistics frame, and typography to its actual content. Large statistics or long category names may need a wider frame or canvas; sparse or dense data may need different point settings. Save those adjustments in the figure configuration and inspect the revised result.
