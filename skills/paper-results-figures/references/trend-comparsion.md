# Trend Comparison

Category ID: `trend-comparsion` (the requested spelling). `trend-comparison` is a spelling alias. Compare continuous response trends across two or more models, two continuous metrics within one model, or explicitly ordered categorical profiles. This is distinct from paired agreement scatter and categorical distribution comparison.

## Input contract

Use long CSV data. Map `x`, `value`, `model`, optional `metric` and optional `id` to actual columns; these keys do not prescribe column names. `value` and continuous `x` must be numeric, with strict conversion. IDs remain strings. Establish the sampling unit, metric identity/units, dependence, and whether categorical values are raw measurements or established summaries before analysis. `sampling_unit` records that meaning; omitted metadata does not establish independence.

- `mode: continuous`: one row per observed response at a numeric covariate, one metric and one or more models. Duplicate covariate values are allowed. OLS uses every finite row within each series; it does not pair, average, impute or weight rows. More than one row from the same sampling unit requires an established repeated/clustered analysis before inferential use.
- `dual_axis: true`: continuous mode, exactly one model and two metrics in long form. Independent observations within each metric remain required for the displayed OLS inference. The metrics may have different units and x availability. Separate, fully labeled numeric y axes use an affine display transform; every calculation and saved value remains in original units. This view does not establish association between metrics.
- `mode: categorical`: one numeric value for each model/metric/category key. Duplicate keys fail rather than being averaged. Supply established summaries or an explicitly justified preparation step for raw replicates. `category_order` declares a scientific or presentation order; otherwise first appearance is retained. Missing cells become gaps in the line. Equal category spacing does not imply a continuous quantity, and no regression or inference is performed.

Missing/nonfinite mapped x/value/model/metric values fail by default. `missing: omit` explicitly retains all finite observations and records source-row exclusions. Missing optional IDs do not silently change the statistical sample. An omitted `metric` produces the generic display identity `Metric A`; establish the scientific identity through `y_label`/metadata for a real analysis.

## Continuous regression and uncertainty

When the brief establishes a finite scientific covariate domain, set `x_limits` to that domain (or a justified narrower view that retains every observation). This is a scientific bound, not an arbitrary cosmetic override. Automatic padding must not produce fitted values outside that domain unless the user explicitly requests and scientifically justifies such extrapolation. Validate that every retained X value lies inside the established domain. Without a finite established domain, use the measured automatic numeric axis; never infer a scientific domain merely from the observed minimum and maximum.

`regression` is `linear` by default. `quadratic` and `cubic` explicitly fit raw-power polynomial OLS; use them only when supported scientifically. Every fit needs more than degree + 2 observations and more than degree distinct x values. The default `fit_extent: axis` evaluates every fitted model across the complete requested numeric x axis so lines and bands reach both panel edges. This can extrapolate beyond an individual series' observed covariate range: those prediction rows are explicitly flagged, their counts and original observed ranges are saved, and no observations or fitting samples are added. Explain extrapolation in the manuscript caption; polynomial extrapolation can be particularly unstable. Use `fit_extent: observed` to restrict each curve and band to its observed x range. The default is a pointwise **95% confidence interval for the fitted conditional mean**, not a prediction interval or simultaneous band. Two-series and dual-metric plots show this interval. More than two model series omit it by default to reduce crowding; `show_ci` overrides visibility without changing saved predictions.

`regression: auto` is an explicit exploratory option. Candidate degrees 1–3 are compared using AICc and exact OLS leave-one-out squared prediction error. It retains linear when n < 10. A higher degree replaces the incumbent only with AICc improvement of at least 4 and LOOCV MSE reduction of at least 10%. Candidate diagnostics and the selected degree are saved. This conservative visual heuristic does not establish a biological mechanism, and selected-model ordinary intervals/p-values do not include model-selection uncertainty. Confirm shape on external data or preregister a model for confirmatory inference. Never select polynomial order by favorable p-values.

The top guide uses one **icon-plus-line-plus-name row**, followed by one **shared statistic-name row with aligned per-series values**. Two-model and dual-metric comparisons always keep exactly these two rows when statistics are requested; model names and statistic types are never repeated in the value cells. For example, the single header `Slope (R²):` is followed by each series' `0.xxx (0.xxx)` values. For a crowded fixed-width two-series guide, default Pearson and p-value headings may use the conventional `r` and `p` abbreviations; the resolved display labels and full statistic keys are retained. `statistic_labels` is an optional named display-label map; the labels must preserve the scientific meaning. The guide can display **at most two** types from `slope`, `r_squared`, `pearson_r`, `p_value`. Choose the types from the scientific claim and apply the same types to every series; never automatically hide unfavorable series or choose statistics by observed significance. All computed diagnostics are retained regardless of annotation. `p_value_target: auto` associates an annotated p-value with Pearson correlation when `pearson_r` is chosen, with the two-sided slope/local-derivative t test when `slope` is chosen, and otherwise with the overall regression F test against an intercept-only model. Explicit `pearson`, `slope` or `regression` targets override that rule and must be described clearly in the figure caption. The resolved target is saved; correlation, slope and overall regression p-values are all separately retained. Polynomial local-derivative inference needs `slope_reference`. Per-series significance does not test whether model slopes differ; interaction/paired/clustered trend comparisons need their own established analysis. No multiplicity adjustment is performed.

Linear `slope` is constant. Polynomials have no constant slope. To display a polynomial local derivative, set `slope_reference` to a covariate value within every series' observed range; the label states that reference. Without a reference, requesting a nonlinear/auto regression removes `slope` from annotations while retaining its unavailable status in records. R² is descriptive fit strength, and Pearson r measures linear association even when a polynomial is drawn.

## Categorical layouts

Metric facets keep the model's fixed palette identity. `orientation: horizontal` puts category on the horizontal x axis and numeric values on the vertical y axis. `orientation: vertical` puts category on the vertical axis and numeric values on the horizontal axis, matching a row-based categorical profile. Vertical-category profiles place metric panels side by side and show shared category names only on the leftmost panel. Horizontal-category profiles stack metric panels and show shared category names only below the final panel. Keep a single common category-axis title and metric-specific panel titles. Numeric value ticks remain available for every metric in its original units; one metric is valid. `facet_scales: free` is the default. `fixed` is appropriate only when established units and domains are comparable, not merely because observed ranges resemble one another. Use explicit metric names, units and, when needed, distinct views instead of silently normalizing.

`model_order`, `metric_order`, and `category_order` must include each retained level exactly once. Named `model_labels`, `metric_labels`, and `category_labels` change display text while preserving raw keys. Shapes and fixed color maps can be supplied with `shape_values` and `color_values`; dual-metric maps use metric keys and other modes use model keys. Automatic model colors follow the [fixed focal/comparator hue policy](palette-contract.md#fixed-categorical-slots); an explicit named map retains its assignments, while dual-metric colors remain tied to metric identities. Dual-axis top keys default to the raw metric identities, while numeric axes use full `metric_labels` with units. Optional named `legend_labels` supplies authorized short top keys independently of numeric-axis descriptions; ordinary model guides otherwise honor `model_labels`.

## Style and invocation

Reuse the cached R environment, fixed palettes, measured Arial, numeric formatting and export checks. Default palette is `rainbow-transparent`; gallery examples explicitly select their labeled palettes. Points use the palette's paired-point alpha/darkening. Fit lines use the palette RGB at 0.25 mm; raw points retain the established point opacity/darkening; confidence fills start at opacity min(0.10, preset fill alpha), separately recorded. The top guide measures actual Arial names, the single statistic header and all value cells on the export device. Continuous two-series guides require two fitting columns; larger guides use as many columns as fit without reducing font size. A long legend requires wider `width_mm` or scientifically authorized shorter labels, rather than silent text clipping.

Complete trend figures, including categorical metric facets, start at 57 × 54 mm; `layout_columns: 4` uses 42 mm width. Facet count does not multiply the export width or height. Vertical-category metric panels stay side by side, and horizontal-category metric panels stay stacked inside that canvas. Categorical marks default to 0.65 mm; continuous scatter marks retain 1.1 mm. Explicit point sizes, dimensions and saved settings take precedence. Compact shared category labels, measured strip-title wrapping and axis spacing preserve readable Arial at final print size. Numeric tick choices use each actual final facet width or height and retain metric-specific original scales and all observations. Shared text helpers measure Arial category labels in the actual facet panel. Axes reuse the existing gray 0.25 mm baseline, 0.22 mm tick and 1.3 pt tick length; metric line colors remain the fixed model encodings. `label_angle: auto` chooses a readable 0/45/90° horizontal-category angle; `label_wrap: auto` allows measured wrapping where needed. Explicit angles and dimensions take precedence; impossible geometry fails with a request to widen/tall the canvas or authorize shorter labels. Inspect actual previews at print size, including legend, metric titles, category names, ticks and complete uncertainty extents. Numeric `x_limits`, `y_limits` and dual `secondary_limits` must contain all observations and shown intervals; cropping fails. Corresponding break controls are available. Cosmetic changes do not alter observations or statistics.

```sh
bash scripts/render.sh /absolute/path/to/config.json
```

Start from [the minimal example](../examples/trend-two-models/request.json). Relative input/output paths resolve against the configuration's directory. Absolute external paths are supported. The output is normalized to `<output-parent>/<figure-name>/<figure-name>`, without repeated nesting on replay. Each figure folder contains PDF, editable embedded-Arial SVG, 600 dpi PNG, resolved configuration, unchanged source snapshot, retained/excluded data, unrounded fitted values/95% intervals, complete statistics and session record. All real input and machine-specific records stay outside this generic skill.

## Deterministic synthetic coverage

Public examples use supplied fixed CSVs for two-model linear, polynomial auto selection, one-model dual-metric, multi-model continuous and categorical facets in both orientations. Each example directory links its scientific Prompt and input CSV.

Automatic continuous axes use the shared nearby-major-tick completion rule. Measured endpoint glyph gutters retain readable first/last tick labels inside the export canvas; explicit limits and breaks remain authoritative.

Short categorical numeric axes prefer readable regular ticks spanning the view, including round domain endpoints when they belong to that grid. Reserve actual Arial half-glyph gutters at outer edges and between panels; compress the data panels within the complete canvas rather than dropping scientifically meaningful endpoints or shrinking tick text. Explicit breaks remain authoritative.
