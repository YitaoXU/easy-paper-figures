# R Environment

Run `bash scripts/ensure_environment.sh` before rendering; `scripts/render.sh` does this automatically. Runtime records live outside the skill directory. The default cache root is `${XDG_CACHE_HOME:-$HOME/.cache}/paper-results-figures`, overridable with `PAPER_FIGURES_CACHE`. A successful check is saved there as `environment.json`, with a companion `environment.ready` fingerprint and `environment-session.txt`. Existing R packages are reused. Missing packages are installed from CRAN into the external cache's `library/` directory; no global library or startup file is edited.

The fast path reads the success record and compares a lightweight identity made from the host, operating system, architecture, Rscript path and file metadata, dependency list, and environment-check script. It does not start R, scan installed packages, or contact CRAN. Ordinary rendering still loads its required packages and writes session information for reproducibility.

Use `bash scripts/ensure_environment.sh --refresh` after intentionally changing R or packages, or after a package/device failure. The lightweight identity is not a full installation inventory and may not detect an in-place change elsewhere inside R. A refresh invalidates the previous success marker before checking. A failed check never creates a success marker. Do not repeatedly retry installation failures; report the specific missing dependency or network/device issue.

Set `PAPER_FIGURES_CACHE` to an absolute writable directory outside the skill to override the default runtime location. Use the same value for the environment check and render. Never bundle runtime records or libraries with the skill: regenerate them on a new machine. Environment records may contain actual machine paths because they are operational state, and must remain outside the generic skill package.

Rscript must already be available on PATH. If it is absent, the helper records the failure and stops. Resolve the operating-system installation separately rather than invoking an unrequested system package manager. Required packages are `ggplot2` (>= 3.5.0), `jsonlite`, `svglite`, `ragg`, and `systemfonts`. Actual Arial regular, bold, italic, and bold italic faces must be installed. The current SVG embedding helper requires individual TrueType files. No font binaries are bundled with the skill.

PDF export uses Quartz on macOS, or a working Cairo backend elsewhere, and must pass embedded-font inspection with the `pdffonts` utility from Poppler. Never fall back to the standard PDF device's generic font families. SVG embeds the resolved Arial faces while preserving editable text. PNG renders with ragg and the resolved Arial family. The environment check renders and verifies all three formats before marking the environment ready. Missing fonts, an unsupported backend, or missing verification utilities produce a specific error rather than a substituted-font figure.
